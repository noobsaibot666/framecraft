# Dashboard

The Dashboard (`/`) is Framecraft's production workspace home — library totals, activity health, and quick jumps back into recent work.

## What You Can Do

- Search across recent prompts, top-rated prompts, and recent results at once — the search filters everything on the page live
- Jump straight into Prompt Craft, a new Project, the Generation Queue, Import, Recipes, or SREFs
- Resume the last prompt you touched in one click
- Drill into any stat, tag, provider, project, or token to jump to its filtered view

## Page Sections, Top to Bottom

1. **Search bar** — filters recent prompts, top-rated prompts, and recent results by title, text, tag, or notes
2. **First-run guide** — shown only when the library has zero prompts (see [Getting Started](/framecraft/user-guide/getting-started/))
3. **Library totals** — Total Prompts, Total Results, Winners, Win Rate, No Results (prompts never generated)
4. **Recent Wins** — the last four winning results as thumbnail cards, linking to the full winners view
5. **Top Tags** — most-used tags as click-through chips
6. **Provider Performance** — win rate per provider with prompt/win counts
7. **Production Health (this week)** — prompts crafted, results reviewed, win rate, a Needs Review alert, active projects, queue depth alert, and a 7-day activity sparkline
8. **Continue where you left off** — one-click resume of your most recently touched prompt
9. **Main grid** — Recent Prompts, Recent Results, Active Projects, Needs Review, Proven Tokens, Winner Tokens, and Top Rated
10. **Quick Actions** — Queue (with a live depth badge), Import, Recipes, SREFs
