# Getting Started

Framecraft opens on the Dashboard (`/`) — your production workspace home. On a brand-new, empty library, the Dashboard shows a 3-step onboarding guide instead of the usual stats, which disappears permanently after your first prompt is created:

1. **Craft** — write your first prompt in Prompt Craft
2. **Queue / Generate** — send it to a provider through the Generation Queue
3. **Import / Review** — bring the generated result back in and score it

That three-step shape *is* Framecraft's core loop, and everything else in the app exists to make each step smarter over time.

## The Core Loop, End to End

1. **Craft a prompt** in [Prompt Craft](/framecraft/user-guide/prompt-craft/) — field-by-field or free text, pulling from your token library's proven combinations as it grows.
2. **Queue it** in the [Generation Queue](/framecraft/user-guide/results-and-queue/) and send it to whichever provider you're using (Midjourney, DALL·E, Firefly, Ideogram, Flux, and others).
3. **Import the result** and score it — Overall rating plus Advanced Scoring (realism, brand fit, composition, lighting, AI-look risk, reuse potential) and a 16-point AI Artifact Checklist.
4. **Mark winners and failures.** This is what actually trains the library: token quality scores, proven combinations, and reference impact scores all derive from which results you mark as winners.
5. **Judge close calls** in the [Comparison Lab](/framecraft/user-guide/comparison-lab/) when you have multiple candidates and need a defensible pick.
6. **Reuse what worked** — as [Recipes](/framecraft/user-guide/library-and-tokens/), as proven token combinations the app surfaces on its own, or as forked prompt versions.

## Where to Go for Larger Work

- Running a full ad campaign or a multi-shot creative direction? Start a [Project](/framecraft/user-guide/projects/) instead of a bare prompt.
- Doing pre-production for a video shoot — script, characters, locations, shot list? Use [Cinema Studio](/framecraft/user-guide/cinema-studio/), a separate, independent workspace from the image-ad project flow.

## Resuming Work

The Dashboard always shows **Continue where you left off** (one-click resume of your most recently touched prompt), Recent Prompts, Recent Results, Active Projects, and anything flagged as **Needs Review** — results that were imported but never scored.
