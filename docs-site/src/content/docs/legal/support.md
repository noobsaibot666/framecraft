For help with Framecraft — bugs, license/activation issues, or feature questions — contact **exposeuberlin@gmail.com**. Include how you installed it (Mac App Store or direct download), the page involved (Dashboard, Prompt Craft, Cinema Studio, Comparison Lab, Generation Queue, References, or Projects), and, for a bug report, the steps that led to it.

For license key or activation problems specifically, see [Licensing & Activation](/framecraft/legal/licensing-and-activation/) first — recovering a lost key or freeing up a device activation can be self-served from there.

If an AI-assisted feature (prompt drafting, image analysis, Cinema Studio's director's brief, or the Project Assistant) is failing or returning unexpected results, first confirm your configured provider's API key is valid and has available quota in Settings — Framecraft calls that provider (Anthropic, OpenAI, or DeepSeek) directly with your own key, so an expired or rate-limited key is the most common cause.
