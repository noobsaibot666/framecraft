# Support

For Framecraft support — bugs, questions, or feature requests — contact the developer:

- Developer: Alan Alves
- Website: [alan-design.com](https://alan-design.com/)
- Email: exposeuberlin@gmail.com

When reporting an issue, include:

- Framecraft version (from Settings)
- Operating system and version
- The affected page or workflow (e.g. Prompt Craft, Cinema Studio, Comparison Lab)
- A short description of the expected vs. actual behavior
- Any error message shown by the app

## Library Issues

If a portable library on a NAS or external drive won't open, see [Architecture](/framecraft/technical/architecture/) for the known WAL-header failure mode and its automatic repair path before reporting it as a bug — most NAS open failures are already handled automatically on next launch.
