# Framecraft Documentation

Framecraft is a local-first desktop workspace for advertising-grade AI image and video prompt engineering. It combines prompt authoring, a learning token library, reference and result management, comparison judging, and multi-stage project tooling in one Tauri 2 application.

The docs are organized around the same multi-product documentation pattern used by Darkwave, Creative Director Suite, and CineFlow Suite:

- Product direction and release scope
- Technical architecture and data handling
- User guide workflows
- Legal and privacy material
- Development and deployment notes

## Core Workflow

1. Craft a prompt — field-by-field or free text — pulling from a token library that learns which combinations actually win.
2. Send it through the Generation Queue to a provider, then import the result back in for scoring.
3. Judge results against each other in the Comparison Lab, and let winners feed the library's recommendations and avoidance patterns.
4. Run richer work — ad campaigns, shot sequences, storyboards — inside Projects, or a full script-to-shot-list pipeline in Cinema Studio.
