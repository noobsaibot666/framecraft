# References

References (`/references`) is the library of **visual input material** — images and videos you feed *into* prompts as inspiration or generation input. It's distinct from the Prompt Library, which holds the text prompts you write: References holds the pictures that inform or accompany them.

## Where References Come From

- Uploaded or dropped directly on the References page
- **Save as Reference** on a Result — turn one of your own generated outputs into reusable material
- The Image Analyzer — save an analyzed image as a reference
- Video Frames — extract and save a frame from a video
- Attached to a Project's mood board, where it surfaces back to you as an "Inspiration" when crafting prompts inside that project

## Why It Matters Beyond Storage

A reference isn't just stored — it gets **linked** to the prompts and results it influenced, tagged with a role (style, composition, lighting, product, character, frame, or failure-example). That link is what makes a reference more than browsable inventory:

- In Prompt Craft, a project's linked references surface as **Inspirations**, and its best-performing references surface as **Impact Refs**
- **Impact score** answers "does this image actually correlate with winners?" — weighted 60% on results it was directly linked to that won, and 40% on projects it's attached to whose prompts won. A high-scoring reference is worth reusing; one with no score is just inventory.

## What You Can Do

- Browse references as cards — thumbnail, kind badge, title, tags, best-use note, risk-notes warning, star rating, win count, provider
- Search by title, tags, or notes; filter by kind (Image, Frame, Result, Source, Mood, Product, Style) and by rating
- Drag and drop images or videos straight onto the library to import as new references
- Delete a reference from its card (two-click confirm)
- Open a reference to edit its full record or create a new one

## Reference Detail (`/references/:id`, `/references/new`)

Image/video drop zone, Title/Kind/Description/Best Use/Risk Notes/Notes fields, a 5-star rating that shows Impact once saved, metadata (Provider, Category, Source URL, Tags), and a **Linked To** list of every prompt and result that references this image, each labeled by role.
